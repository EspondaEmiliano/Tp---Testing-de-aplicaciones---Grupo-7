================================================================================
GUÍA DE COMANDOS DE EJECUCIÓN - SUITE DE AUTOMATIZACIÓN RENDIX
================================================================================

Este documento contiene todos los comandos necesarios para ejecutar la suite de 
pruebas automatizadas con Maven y Playwright, desglosados por lote y por caso 
individual.

> NOTA SOBRE MAVEN WRAPPER EN WINDOWS:
  - Puedes usar 'mvn' si tienes Maven en el PATH, o '.\mvnw.cmd' utilizando el 
    wrapper incluido en la raíz del proyecto.
  - Para ejecutar Chromium en segundo plano (sin abrir la ventana gráfica del 
    navegador), agrega el parámetro '-Dheadless=true' al final de cualquier comando.
    Ejemplo: .\mvnw.cmd test "-Dgroups=lote-login" "-Dheadless=true"

================================================================================
COMANDOS GLOBALES Y REPORTES
================================================================================

1. Ejecutar TODOS los tests del proyecto:
   Maven:         mvn test
   Maven Wrapper: .\mvnw.cmd test

2. Limpiar evidencias previas y ejecutar TODOS los tests desde cero:
   Maven:         mvn clean test
   Maven Wrapper: .\mvnw.cmd clean test

3. Levantar el servidor interactivo de Allure Report (Dashboard web en vivo):
   Maven:         mvn allure:serve
   Maven Wrapper: .\mvnw.cmd allure:serve

4. Generar reporte HTML estático de Allure (en target/site/allure-maven-plugin/):
   Maven:         mvn allure:report
   Maven Wrapper: .\mvnw.cmd allure:report
