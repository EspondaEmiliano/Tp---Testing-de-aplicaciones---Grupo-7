================================================================================
GUÍA DE COMANDOS DE EJECUCIÓN - SUITE DE AUTOMATIZACIÓN RENDIX
================================================================================

Este documento contiene todos los comandos necesarios para ejecutar la suite de 
pruebas automatizadas con Maven y Playwright, alineados estrictamente con la 
matriz oficial de casos de prueba (ID-001 al ID-093, excluyendo ID-075).

> NOTA SOBRE MAVEN WRAPPER Y PROPIEDADES EN WINDOWS:
  - Puedes usar 'mvn' si tienes Maven en el PATH, o '.\mvnw.cmd' utilizando el 
    wrapper incluido en la raíz del proyecto.
  - Para ejecutar en modo oculto (headless), agrega '-Dheadless=true'.
  - Para elegir el navegador ('chrome' o 'msedge'), agrega '-DbrowserChannel=chrome'.
  - Por defecto, 'mvn test' falla el build si algún test detecta un bug en la app
    (testFailureIgnore=false). Para continuar hacia Allure Report ignorando fallos
    en la consola, agrega '-DtestFailureIgnore=true'.

================================================================================
⚡ COMANDO RÁPIDO: LIMPIEZA TOTAL, EJECUCIÓN COMPLETA Y APERTURA DE ALLURE REPORT
================================================================================
Ejecuta este bloque para:
  1. Eliminar todos los resultados, reportes previos y trazas guardadas (target/ y resultados/).
  2. Volver a ejecutar TODOS los tests de la suite desde cero.
  3. Levantar automáticamente el dashboard web interactivo de Allure Report en el 
     navegador con la información exclusiva de las pruebas recién ejecutadas.

--- En PowerShell (Recomendado para Windows) ---
Remove-Item -Recurse -Force target, resultados -ErrorAction SilentlyContinue; .\mvnw.cmd clean test "-DtestFailureIgnore=true" allure:serve

--- En CMD (Símbolo del sistema de Windows) ---
if exist resultados rmdir /s /q resultados & .\mvnw.cmd clean test "-DtestFailureIgnore=true" allure:serve

--- En Bash / Git Bash / macOS / Linux ---
rm -rf target resultados && ./mvnw clean test -DtestFailureIgnore=true allure:serve

--- Variante en modo Headless (navegador oculto hasta abrir Allure) ---
PowerShell:    Remove-Item -Recurse -Force target, resultados -ErrorAction SilentlyContinue; .\mvnw.cmd clean test "-Dheadless=true" "-DtestFailureIgnore=true" allure:serve
Maven Wrapper: .\mvnw.cmd clean test "-Dheadless=true" "-DtestFailureIgnore=true" allure:serve
Maven:         mvn clean test -Dheadless=true -DtestFailureIgnore=true allure:serve


================================================================================
COMANDOS GLOBALES Y REPORTES INDIVIDUALES
================================================================================

1. Ejecutar TODOS los tests del proyecto:
   Maven:         mvn test
   Maven Wrapper: .\mvnw.cmd test

2. Limpiar evidencias previas y ejecutar TODOS los tests desde cero:
   Maven:         mvn clean test
   Maven Wrapper: .\mvnw.cmd clean test

3. Levantar el servidor interactivo de Allure Report (Dashboard web en vivo):
   Maven:         mvn allure:serve
   Maven Wrapper: .\mvnw.cmd allure:serve

4. Generar reporte HTML estático de Allure (en target/site/allure-maven-plugin/):
   Maven:         mvn allure:report
   Maven Wrapper: .\mvnw.cmd allure:report
